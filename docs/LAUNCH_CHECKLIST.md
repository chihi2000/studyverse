- [ ] Change the admin password (Mon compte → Mot de passe)
- [ ] Remove the test club admin from ISTIC DEV SPACE (Administration → Clubs → Gérer → Retirer), then delete `club-admin.test@studyverse.app`
- [ ] "Mot de passe oublié": create a Resend account and provide `RESEND_API_KEY` as a Vercel env var
- [ ] Privacy policy and terms of use pages (have them reviewed for Tunisian law; check INPDP declaration)
- [ ] Optional: custom domain (e.g. studyverse.tn) instead of studyverse-six-puce.vercel.app
- [ ] Optional: privacy-friendly usage analytics, to measure adoption before choosing a business model
- [ ] Later: pricing / business model for Tunisia (local payments, Vercel Pro once commercial)
